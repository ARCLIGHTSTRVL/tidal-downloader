<a id="first-launch"></a>
## 처음 실행하기

1. 앱을 열고 로그인 안내의 **Login**을 누릅니다.
2. Tidal 창에서 로그인을 마칩니다. 검색, 스트리밍과 다운로드에는 정상적인 Tidal 로그인 상태와 해당 음악에 대한 이용 권한이 필요합니다.
3. **Settings → 다운로드 위치**에서 음악을 저장할 폴더를 고릅니다. 기존 라이브러리를 사용하려면 음악이 들어 있는 폴더를 선택하세요.
4. **음질**을 선택한 뒤 아티스트, 앨범, 곡 또는 플레이리스트를 검색합니다.

다운로드 폴더를 선택할 때 별도 이미지 저장 위치가 없으면 **앨범 아트 다운로드 위치**가 그 안의 `art` 폴더로 설정됩니다. 이후 따로 바꿀 수 있습니다.

**자동 토큰 갱신**을 켜 두면 앱이 로그인 세션을 갱신합니다. 그래도 Tidal에서 다시 로그인을 요구할 수 있습니다. **Settings → 언어**에서 한국어와 영어를 전환할 수 있으며, 일부 버튼과 화면 이름은 영어로 표시됩니다.

<a id="search--discovery"></a>
## 검색과 음악 탐색

검색창에 이름을 입력한 뒤 아래에 나타나는 결과를 선택하거나 **Enter**를 눌러 전체 결과를 엽니다. 아티스트, 앨범, 곡과 플레이리스트를 찾을 수 있습니다.

홈에는 즐겨찾기한 아티스트, **My Playlists**, 최근 열어 본 아티스트·앨범·EP·싱글·플레이리스트가 표시됩니다. 항목이 있는 목록만 나타나며, **View all**로 더 볼 수 있습니다.

- **아티스트**를 열면 앨범과 EP·싱글을 볼 수 있습니다. 하트는 앱의 아티스트 즐겨찾기를 추가하거나 해제합니다.
- **앨범**을 열면 수록곡을 재생하거나 다운로드할 수 있습니다. 아티스트 이름을 누르면 해당 아티스트 화면으로 이동합니다.
- 확대 보기를 지원하는 **커버 이미지**를 누르면 큰 이미지가 열립니다.

<a id="playlists"></a>
## 플레이리스트

검색 결과나 **My Playlists**에서 플레이리스트를 열 수 있습니다. My Playlists에는 Tidal에서 직접 만든 목록과 즐겨찾기한 목록이 함께 표시됩니다. **Recent Playlists**에는 현재 앱 실행 중 열어 본 목록이 표시됩니다.

바로 열려면 `/playlist/<UUID>`가 들어 있는 Tidal 링크 또는 플레이리스트 UUID만 검색창에 붙여 넣고 **Enter**를 누르세요. 로그인한 계정으로 접근할 수 있는 목록이어야 합니다. My Playlists에 보이지 않는 목록은 직접 링크로 열어 보세요.

플레이리스트 화면에서 곡을 누르면 재생합니다. 곡 옆 다운로드 아이콘은 해당 곡을, 플레이리스트 정보 아래의 다운로드 아이콘은 전체 목록을 받습니다.

플레이리스트는 다음과 같은 별도 구조로 저장됩니다.

```text
다운로드 폴더/
  playlists/
    플레이리스트 이름/
      01 - 곡 제목.flac
      02 - 다른 곡.m4a
```

트랙 번호는 플레이리스트 순서입니다. 일반 폴더·파일 이름 규칙은 이 구조에 적용되지 않습니다. Library에서는 별도의 **Playlists** 그룹으로, Tag Editor에서는 플레이리스트 폴더별로 표시됩니다. 같은 곡의 앨범용 파일과 플레이리스트용 파일을 함께 보관할 수 있으며, 플레이리스트의 다운로드 완료 표시는 그 목록에 저장한 파일을 기준으로 합니다.

**플레이리스트 진행률 옆의 ✕**는 다음 곡을 받기 전에 전체 작업을 멈춥니다. 현재 다운로드 중인 곡은 완료될 수 있습니다. 그 곡도 취소하려면 해당 곡의 진행 중인 다운로드 행이나 Downloads 화면에서 취소하세요.

<a id="audio-quality"></a>
## 음질

**Settings → 음질**은 재생과 다운로드에 요청할 음질을 함께 정합니다.

| 설정 | 요청하는 오디오 | 필요할 때 사용하는 하위 음질 |
| --- | --- | --- |
| **Max** | 최대 24-bit / 192 kHz FLAC | 더 낮은 해상도의 무손실, 이후 High AAC |
| **HiFi** | 16-bit / 44.1 kHz FLAC | High AAC |
| **High** | 320 kbps AAC | 이 단계에서는 AAC가 정상입니다 |

실제 결과는 곡과 Tidal이 현재 세션에 제공하는 음원에 따라 달라집니다. Max를 골라도 모든 곡이 고해상도로 제공되지는 않습니다. Max와 HiFi 모두 손실 음원인 **High**로 내려갈 수 있으며, 이 경우 `.m4a`로 저장합니다. FLAC은 `.flac`로 저장하며, 제공된 오디오는 재인코딩하지 않습니다.

설정값만 보지 말고 실제 곡의 음질 정보도 확인하세요. **사용 가능한 음질 확인**은 현재 세션에서 일부 곡을 시험해 무손실 제공 여부와 AAC로 내려간 결과를 보여 줍니다. 전체 카탈로그에 대한 보장은 아닙니다. 재생 시작까지 걸리는 시간은 곡, 연결 상태와 필요한 처리에 따라 달라집니다.

<a id="album-art"></a>
## 앨범 아트

**Settings → 앨범 아트 화질**은 다운로드 파일에 넣을 이미지의 요청 해상도를 정합니다.

| 설정 | 요청 크기 |
| --- | --- |
| **High** | 1280 × 1280 |
| **Standard** | 640 × 640 |
| **Low** | 320 × 320 |

요청한 이미지가 없으면 더 작은 크기를 시도합니다. 커버 확대 화면에서는 이미지를 별도로 저장할 수도 있습니다. 저장 위치는 **앨범 아트 다운로드 위치**이며, 지정하지 않았다면 오디오 다운로드 폴더를 사용합니다.

카드가 움직이지 않게 하려면 설정에서 **앨범 아트 호버 틸트**를 끄세요.

<a id="downloading"></a>
## 음악 다운로드

- **한 곡:** Search, 앨범 또는 플레이리스트에서 곡 옆 다운로드 아이콘을 누릅니다. 재생 바에도 다운로드 버튼이 있습니다.
- **앨범 전체:** 앨범 정보 아래의 다운로드 아이콘을 누릅니다. 이미 다운로드한 것으로 표시되는 곡은 건너뜁니다.
- **앨범 취소:** 진행률 옆의 중지 버튼을 누릅니다. 앨범 작업을 멈추고 현재 받는 곡에도 취소를 요청합니다.
- **개별 다운로드 취소:** Downloads에서 진행 중인 행의 **✕**를 누릅니다. 다시 시도하기 전에 결과를 확인하세요.

서로 다른 아티스트나 플레이리스트가 같은 폴더 이름을 쓰게 되면 구분할 이름을 입력하라는 안내가 나올 수 있습니다. 기록된 이름은 같은 아티스트나 플레이리스트를 나중에 받을 때 다시 사용합니다.

취소를 요청했다고 디스크에 아무것도 저장되지 않은 것은 아닙니다. 이미 파일이 저장됐거나 정리가 남아 있을 수 있습니다. 남은 파일을 지우거나 재시도하기 전에 Downloads의 결과를 읽어 보세요.

<a id="downloads-page"></a>
## 다운로드 내역

**Downloads**는 현재 앱 실행 중 시도한 다운로드의 진행률과 완료·실패·취소 결과를 보여 줍니다. 오디오는 저장됐지만 태그, 라이브러리 등록 또는 임시 파일 정리가 끝나지 않았다는 안내가 나올 수도 있습니다. 음악 파일이 생겼더라도 이런 세부 결과를 확인하세요.

- 행을 누르면 **Tidal에서 스트리밍**합니다. 저장된 파일을 재생하려면 Library에서 여세요.
- **진행 중인 행의 ✕**는 취소를 요청합니다. 끝난 행에서는 내역만 지웁니다.
- **Clear finished downloads**는 끝난 내역을 지우고 진행 중인 항목은 남깁니다.

이 내역은 앱을 종료하면 지워집니다. 내역을 지워도 오디오 파일이나 라이브러리의 다운로드 완료 표시는 없어지지 않습니다.

<a id="library"></a>
## 라이브러리

Library는 설정된 다운로드 폴더를 읽어 로컬 음악을 아티스트와 앨범별로 보여 줍니다. 플레이리스트는 별도 그룹입니다. 곡을 누르면 저장된 파일을 재생합니다.

- **목록 보기:** 아티스트·앨범·곡을 펼쳐 봅니다. **앨범 정렬**에서 아티스트, 앨범, 연도, 최근 추가 순서를 고를 수 있으며 보기를 전환해도 목록의 정렬 선택은 유지됩니다.
- **격자 보기:** 앨범이나 플레이리스트 커버를 누르면 곡 목록이 열립니다. 커버 크기 조절 기능으로 카드 크기를 바꿀 수 있습니다.
- **검색:** 아티스트, 앨범 또는 곡 이름으로 라이브러리를 좁혀 봅니다.

**Refresh library**는 표준 FLAC으로 변환이 필요한 이전 다운로드를 확인한 뒤 폴더와 이미지를 다시 읽습니다. v1.0.5에서는 이 기능이 새로고침에 포함되어 있으며 별도의 Remux 버튼은 없습니다. 수동 새로고침에서는 빈 폴더 삭제나 잘못 배치된 플레이리스트 파일 정리를 제안할 수 있습니다. 내용을 확인한 뒤 실행하세요.

### 로컬 음악 삭제

Library의 삭제 버튼은 목록에서만 숨기는 것이 아니라 **디스크의 파일을 삭제**합니다. 아티스트·앨범·플레이리스트 단위 삭제는 확인을 거치며, 개별 곡 삭제 버튼은 바로 실행합니다.

그룹 삭제는 선택한 곡들을 대상으로 합니다. 아티스트와 플레이리스트 정리에서는 관련 `folder.jpg` 이미지와 빈 폴더도 삭제할 수 있습니다. 다른 파일이 남아 있거나 충돌·검증 문제가 있으면 폴더가 그대로 남을 수 있습니다. 삭제가 끝나지 않으면 라이브러리를 다시 읽고 남은 파일을 알려 줍니다. 해당 파일을 쓰는 프로그램을 닫고 결과를 확인한 뒤 다시 시도하세요.

<a id="tag-editor"></a>
## 태그 편집기

Tag Editor는 설정된 다운로드 폴더를 불러옵니다. **Open Files**, **Open Folder** 또는 드래그 앤드 드롭으로 다른 파일·폴더를 추가할 수 있습니다. **Refresh**는 불러온 폴더를 다시 읽습니다. **Clear directories**는 선택한 폴더를 편집기에서만 빼며 디스크 파일은 삭제하지 않습니다.

앨범이나 플레이리스트 카드를 열어 파일을 편집하세요.

1. 곡을 선택하고 메타데이터를 바꾼 뒤 **Save**를 누릅니다. **Save Album**은 현재 그룹에서 수정한 곡들을 저장합니다. **Revert**는 선택한 곡의 저장하지 않은 메타데이터 초안을 버립니다.
2. 공통 정보를 바꾸려면 앨범 단위의 Album, Album Artist, Artist, Year, Genre, Composer 필드와 **Apply to All N Tracks**를 사용합니다.
3. **Change Art**는 이미지 파일 선택 창을 엽니다. 앨범 단위에서는 이미지를 고른 뒤 **Apply to All N Tracks**를 누릅니다. 개별 곡에서는 이미지를 선택하면 그 곡에 바로 기록하며, 메타데이터 초안과 별도로 처리합니다.

태그를 저장하면 저장된 폴더·이름 규칙에 맞춰 파일이 이동할 수도 있습니다. 태그 기록, 파일 이동과 라이브러리 등록은 결과가 다를 수 있으므로 안내를 읽어 보세요. 라이브러리가 사용 중이면 태그만 저장하고 이동을 미룰 수 있습니다.

저장이 거절되거나 중단되거나, 결과가 현재 표시된 파일과 일치하는지 확인할 수 없으면 초안을 남기고 해당 행에 주의 표시를 할 수 있습니다. 초안이 남았다고 **디스크 파일이 그대로라는 뜻은 아닙니다**. 특히 다른 프로그램이 파일을 옮기거나 교체했다면 안내된 경로를 확인하고 새로고침한 뒤 다시 시도하세요. 초안은 작업 중인 내용이므로 앱을 종료하기 전에 저장해야 합니다.

폴더를 직접 정리하려면 미저장 편집을 먼저 저장한 뒤 **Reorganize files to match folder structure**를 사용하세요. 미리보기에서 이동, 충돌과 중복 삭제 항목을 확인한 뒤 적용합니다. 대상 위치에 같은 파일이 보존되는 것으로 확인되면 중복된 원본을 삭제할 수 있습니다.

이전 버전에서 받은 DASH 형식 파일은 편집 내용이 라이브러리 인덱스에만 저장된다는 안내가 나올 수 있습니다. **Library → Refresh library**로 표준 FLAC 변환을 시도한 뒤 파일을 다시 열어 편집을 이어 가세요.

<a id="player-bar"></a>
## 재생 바

곡을 선택하면 재생 바가 나타납니다. 이전 곡, 재생·일시정지, 다음 곡, 탐색, 볼륨과 다운로드 기능이 있습니다.

- **셔플:** 현재 앨범이나 폴더 안에서 재생 순서를 섞습니다.
- **반복:** 끄기, 한 곡, 현재 앨범·폴더 순서로 전환합니다.
- **탐색:** 진행 막대를 누르거나 드래그해 곡 안에서 이동합니다.
- **음질 표시:** 현재 곡에 대해 확인할 수 있는 음질 정보를 보여 줍니다.
- **커버와 아티스트 링크:** 해당 정보가 있으면 관련 상세 화면을 엽니다.

<a id="audio-device-picker"></a>
## 오디오 출력 장치

재생 바의 스피커 아이콘을 열고 출력을 선택한 뒤, 선택된 장치의 톱니바퀴를 눌러 **Device settings**를 엽니다. 옵션은 장치별로 저장합니다.

- **Use exclusive mode:** Windows에서는 WASAPI 독점 모드, macOS에서는 Core Audio Hog Mode를 사용하는 네이티브 출력을 요청합니다. 네이티브 오디오 구성 요소와 장치·드라이버가 해당 출력을 지원해야 합니다. 장치를 점유하는 동안 다른 앱의 소리가 나오지 않을 수 있습니다.
- **Force volume:** 독점 모드에서 사용할 수 있습니다. 앱 볼륨을 100%로 고정하고 슬라이더를 잠급니다. 출력 장치의 볼륨 조절을 사용하세요.

네이티브 재생을 시작하지 못하면 공유 재생으로 전환될 수 있습니다. 따라서 스위치를 켠 것만으로 독점 출력이나 비트 퍼펙트 재생을 확인할 수는 없습니다. 장치가 사용 중이거나 소리가 나지 않으면 다른 오디오 앱을 닫고 출력을 다시 선택하거나 독점 모드를 끄세요. 지원 샘플 레이트는 장치와 드라이버에 따라 다릅니다.

<a id="settings-reference"></a>
## 설정

대부분의 설정은 바꾸는 즉시 저장합니다. 다운로드 이름 규칙과 앨범 분류는 별도의 **저장** 버튼을 사용합니다.

| 설정 | 기능 |
| --- | --- |
| **계정 / 자동 토큰 갱신** | 로그인·로그아웃과 세션 갱신을 관리합니다. |
| **백그라운드 재생 · 트레이** | 창을 닫아도 트레이나 메뉴 막대에서 앱을 계속 실행합니다. 해당 메뉴로 창을 다시 열거나 종료합니다. |
| **음질** | 재생과 다운로드에 요청할 음질입니다. [음질 안내](#audio-quality)를 참고하세요. |
| **앨범 아트 화질 / 호버 틸트** | 파일에 넣을 이미지의 해상도와 카드 효과를 정합니다. |
| **다운로드 위치** | 오디오를 저장하고 라이브러리를 표시할 기준 폴더입니다. 다른 폴더를 골라도 기존 라이브러리가 이동하지는 않습니다. |
| **앨범 아트 다운로드 위치** | 별도로 저장하는 커버 이미지의 목적지입니다. |
| **언어** | 한국어 또는 영어를 선택합니다. |

### 초기화

두 초기화 기능 모두 한 번 더 눌러 확인해야 실행됩니다.

- **라이브러리 데이터 초기화:** 앱에서 즐겨찾기한 아티스트와 이미지 캐시를 지웁니다. 다운로드 파일과 완료 표시는 유지합니다.
- **현재 설정 초기화:** 재생, 음질, 다운로드 위치, 이미지 옵션과 이름 규칙을 기본값으로 되돌리고 저장하지 않은 이름 규칙을 버립니다. 언어, 자동 갱신, Tidal 로그인, 다운로드 파일과 라이브러리 인덱스는 유지합니다. 이후 라이브러리가 비어 보이면 기존 다운로드 폴더를 다시 선택하세요.

<a id="download-naming"></a>
## 다운로드 이름 규칙

**Settings → 다운로드**에서 **폴더 구조**와 **파일 이름**을 편집합니다. 이후 받는 앨범·곡에 적용되며, 플레이리스트는 [별도 구조](#playlists)를 사용합니다.

새 설정의 기본값은 다음과 같습니다.

```text
폴더 구조: {album_artist}/{album}
파일 이름: {track_number} - {title}
예시:      Adele/30/01 - Easy On Me.flac
```

업데이트해도 유효한 기존 규칙은 유지됩니다. 확장자는 규칙에 넣지 마세요. 앱이 음원에 맞춰 `.flac` 또는 `.m4a`를 붙입니다.

1. **직접 편집**으로 입력하거나 **태그 조합**으로 만듭니다. 보기를 전환해도 텍스트, 태그와 공백은 유지됩니다.
2. 커서 위치에 태그를 넣거나 **태그 사용법**을 엽니다. 폴더 단계는 `/` 또는 `\`로 구분합니다.
3. **경로 미리보기**를 확인합니다. **미리보기용 곡 정보**를 바꾸면 정보가 없거나 아티스트가 여러 명인 경우를 시험할 수 있습니다. 실제 곡이나 규칙은 바뀌지 않습니다.
4. **저장**을 누릅니다. 저장하지 않고 나가려 하면 저장, 저장 안 함, 계속 편집 중에서 고를 수 있습니다. **변경 취소**는 저장된 규칙으로 되돌립니다.

| 태그 | 의미와 예시 |
| --- | --- |
| `{album_artist}` | 앨범 전체의 대표 아티스트: `Adele` |
| `{artist}` | 해당 곡에 참여한 아티스트: `Adele, Jessie J` |
| `{album}` | 앨범 제목: `30` |
| `{title}` | 곡 제목: `Easy On Me` |
| `{track_number}` | 두 자리 트랙 번호: `01` |
| `{year}` | 발매 연도: `2021` |
| `{genre}` | 제공된 장르: `Pop` |
| `{album_type}` | `Albums`, `EPs`, `Singles`, `Compilations` |
| `{bit_depth}` | 오디오 비트 깊이: `24` |
| `{sample_rate}` | kHz 단위 샘플 레이트: `44.1` |
| `{quality}` | 다운로드한 오디오 음질: `Max` |

앨범을 한 폴더에 모으려면 **앨범 아티스트**를 사용하세요. **곡 아티스트**를 쓰면 협업곡이 별도 폴더로 갈라질 수 있습니다. 정보가 없는 태그는 빈 값이나 대체 이름을 사용할 수 있으니 미리보기의 안내를 확인하세요.

**프리셋**에는 기본, 연도 포함, 음질 포함이 있습니다. 연도 포함은 폴더에 `{album_artist}/{year} - {album}`을 사용합니다. 음질 포함은 파일 이름에 `[{quality}]`를 붙여 `01 - Easy On Me [Max].flac`처럼 만듭니다.

알 수 없는 태그는 글자 그대로 남고 경고가 표시됩니다. 경로에 쓸 수 없는 문자, 예약된 이름과 끝의 점·공백은 출력에서 정리됩니다. 확장자를 직접 넣으면 파일 이름의 일부가 되므로 별도로 적지 마세요.

<a id="album-type-grouping"></a>
## 앨범 유형별 분류

이름 규칙 편집기의 **앨범 분류 설정**을 열고 **앨범 유형별 분류**를 켭니다. 기본 구조에서는 `앨범 아티스트/Albums/앨범`처럼 Albums, EPs, Singles, Compilations 폴더를 추가합니다. **컴필레이션을 Albums 폴더에 합치기**를 켜면 컴필레이션도 Albums에 넣습니다.

**저장**하면 이후 다운로드부터 적용됩니다. 기존 파일은 직접 정리하기 전까지 원래 위치에 남습니다.

기존 라이브러리를 정리하려면 다음 순서로 진행하세요.

1. 이름 규칙과 분류 설정을 저장합니다.
2. **기존 라이브러리 앨범 분류 → 미리보기**를 엽니다.
3. 미리보기의 각 페이지에서 현재 경로, 바뀔 경로, 건너뛸 파일과 충돌을 확인합니다.
4. **적용**을 누르고 결과에서 끝나지 않은 이동이나 라이브러리 갱신 경고를 확인합니다.

저장한 폴더·파일 이름 규칙을 모두 사용하므로 목적지의 두 부분을 확인하세요. 이 화면은 예시 곡으로 보는 경로 미리보기와 별개입니다. 플레이리스트 파일은 원래 위치를 유지합니다. 앨범 유형을 모르거나 커스텀 템플릿에서 앨범의 위치가 명확하지 않으면 건너뛸 수 있습니다.

<a id="library-maintenance"></a>
## 라이브러리 유지보수

해결하려는 문제에 맞는 기능을 사용하세요.

- **TIDAL에서 재동기화 (온라인):** 최신 메타데이터를 받아 저장된 규칙에 따른 태그, 이미지, 폴더와 파일 이름 변경을 미리 보여 줍니다. 인터넷이 필요하며, 미리보기를 확인한 뒤 적용합니다.
- **FLAC에서 재구축 (오프라인):** 버튼 이름과 달리 **FLAC과 M4A**에 들어 있는 Tidal 식별 정보로 다운로드 인덱스를 다시 만듭니다. 최신 메타데이터를 받거나 오디오 파일을 재배치하지는 않습니다. 식별 정보가 없거나 손상된 파일은 건너뛸 수 있습니다.
- **Tag Editor → Reorganize:** 불러온 파일의 메타데이터로 폴더와 파일 이름 변경을 미리 봅니다. [태그 편집기](#tag-editor)에서 설명한 중복 삭제가 포함될 수 있습니다.

다른 태그 편집기를 사용할 때는 `TIDAL_GUID`와 `TIDAL_META` 항목을 유지하세요. 앱이 파일을 식별하고 인덱스를 오프라인으로 복구하는 데 사용합니다.

파일 정리는 디스크 경로를 바꾸므로 제안된 목적지와 최종 결과를 확인하세요. 라이브러리가 사용 중이라는 안내가 나오면 다운로드나 다른 편집이 끝날 때까지 기다립니다. 심볼릭 링크, 정션 또는 변경된 파일 때문에 거절되면 실제 폴더 경로를 사용하고 파일 상태를 새로 읽은 뒤 다시 시도하세요.

<a id="settings-recovery-and-updates"></a>
## 설정 복구와 업데이트

백업에서 설정을 복구했거나, 일부 값을 바로잡았거나, 아직 저장되지 않은 변경이 있으면 설정 화면에 표시됩니다. 저장에 실패하면 화면을 열어 둔 채 **저장 재시도**를 누르거나 이름 규칙을 다시 저장하세요. 복구용 백업 경고는 본 설정은 저장됐지만 백업 갱신만 실패했다는 뜻일 수 있습니다.

복구나 초기화로 다운로드 위치가 기본값으로 돌아가면 기존 음악이 현재 라이브러리 밖에 있을 수 있습니다. **다운로드 위치**에서 원래 폴더를 선택하세요.

**업데이트 확인**은 릴리스 서비스에 연결할 수 있을 때 새 버전을 확인합니다. 다운로드·재시작 버튼이 나타날 수 있지만 현재 서명 방식에서는 자동 설치가 안정적이지 않습니다. [수동 업데이트 안내](../README.ko.md#이전-버전에서-업데이트)를 따라 환경에 맞는 파일을 받고, 트레이·메뉴 막대 실행까지 포함해 앱을 종료한 뒤 업데이트하세요. **GitHub Star**는 프로젝트 저장소를 엽니다.

<a id="mouse--keyboard-shortcuts"></a>
## 마우스와 키보드 조작

- **마우스 측면 버튼:** 이동 기록에서 뒤로 또는 앞으로 갑니다.
- **현재 사이드바 탭을 한 번 더 클릭:** Search는 홈으로, Library와 Tag Editor는 최상위 보기로 돌아갑니다.
- **검색창에서 Enter:** 전체 결과를 열거나 붙여 넣은 플레이리스트 링크·UUID를 엽니다.
- **스페이스바:** 곡이 선택되어 있고 입력칸이나 버튼 같은 조작 요소에 포커스가 없을 때 재생·일시정지합니다.
- **Esc 또는 배경 클릭:** 지원하는 메뉴와 대화상자를 닫습니다. 변경을 적용 중인 작업 창은 닫히지 않을 수 있습니다.

<a id="troubleshooting"></a>
## 문제 해결

**Max나 HiFi를 골랐는데 M4A로 받았습니다.**
Tidal이 AAC를 제공했을 수 있습니다. **사용 가능한 음질 확인**과 실제 곡의 음질 정보를 확인하고 [음질 안내](#audio-quality)를 참고하세요. M4A의 확장자를 FLAC으로 바꿔도 무손실 음원이 되지 않습니다.

**다운로드가 실패하거나 취소됐는데 파일이 남았습니다.**
Downloads의 세부 결과를 읽어 보세요. 태그 기록이나 정리 전에 오디오가 먼저 저장됐을 수 있습니다. 진행 중인 작업을 마치고 안내된 파일을 확인한 뒤 재시도하거나 남은 파일을 정리하세요.

**업데이트나 초기화 뒤 라이브러리가 비어 보입니다.**
먼저 **다운로드 위치**가 기존 음악 폴더인지 확인하고 새로고침하세요. 완료 표시나 기록이 여전히 없으면 오프라인 재구축을 실행하고 건너뛴 파일을 확인합니다.

**앨범 아트나 아티스트 사진이 오래된 이미지로 나옵니다.**
먼저 **Refresh library**를 시도하세요. **라이브러리 데이터 초기화**도 이미지 캐시를 지우지만 아티스트 즐겨찾기까지 지우므로 둘 다 초기화하려는 경우에만 사용하세요.

**음악을 삭제했는데 폴더가 남았습니다.**
이미지나 다른 파일이 남아 있거나 삭제가 거절됐을 수 있습니다. 결과를 확인하세요. 수동 새로고침에서는 실제로 비어 있는 폴더의 정리를 제안할 수 있습니다.

**태그를 저장했는데 미저장 또는 분리된 초안 표시가 남습니다.**
재시도하기 전에 저장 안내와 디스크 파일을 확인하세요. 일부 기록은 이미 끝났을 수 있습니다. 외부에서 옮기거나 교체한 파일을 확인한 뒤 새로고침하고, 초안을 버리려는 경우에만 Revert를 사용하세요.

**Windows에서 드래그 앤드 드롭이 되지 않습니다.**
관리자 권한으로 실행한 앱에는 탐색기에서 파일을 끌어 놓을 수 없습니다. 앱을 일반 권한으로 다시 실행하거나 Open Files / Open Folder를 사용하세요.

**독점 모드가 안 되거나 볼륨 슬라이더가 잠겼습니다.**
공유 재생을 시도하고 같은 장치를 쓰는 다른 앱을 닫으세요. Force volume은 의도적으로 슬라이더를 잠급니다. 해당 옵션을 끄거나 출력 장치에서 볼륨을 조절하세요.

**로그인 안내가 계속 나옵니다.**
Tidal 창에서 로그인을 마치고 네트워크 연결을 확인하세요. Tidal이 세션을 거절하면 제공된 안내에 따라 다시 로그인해야 합니다. 즐겨찾기나 이름 규칙 초기화로 인증 문제를 해결할 수는 없습니다.

다른 문제가 있으면 앱 버전, 운영체제, 재현 순서와 관련 오류 메시지를 적어 [이슈](https://github.com/ARCLIGHTSTRVL/tidal-downloader/issues)를 등록하세요. 로그나 화면을 공유하기 전 계정 정보, 토큰 등 개인정보는 지워 주세요.
