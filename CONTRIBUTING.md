# Contributing

Thanks for your interest in TIDAL DOWNLOADER!

This is a closed-source application. The build artifacts are released here, but the source code is hosted privately and **pull requests are not accepted** at this time.

## What you *can* do

- **Report a bug** — open an [Issue](../../issues/new/choose) using the **Bug report** template. Please include the app version (Settings → About footer), OS, and steps to reproduce.
- **Request a feature** — open an [Issue](../../issues/new/choose) using the **Feature request** template. Describe the user need first, the implementation second.
- **Ask a question / share a tip** — Issues are also fine for these; tag the issue with a `question` label and one of the maintainers will respond.

## What we cannot accept

- Pull requests, patches, or code submissions.
- Issues asking for the source code or build instructions for the proprietary core.
- Issues that boil down to circumventing Tidal's Terms of Service.

## Before opening an issue

- Skim the [User Guide](docs/USER_GUIDE.md) and the [Changelog](CHANGELOG.md) — your question may already be answered.
- Search existing Issues — bug reports often have an existing thread with workarounds.

## Disclaimer

This project is not affiliated with Tidal or Aspiro AB. Issues that ask the maintainers to bypass Tidal's authentication or tier restrictions will be closed without comment.
